# Personal Portfolio Website

A personal portfolio website built with HTML5 to showcase my technical skills, software projects, and professional background. The page provides a central place to explore my work, learn about my experience, and connect with me.

## Overview

This project demonstrates the fundamentals of semantic HTML and webpage structure while organizing professional information into a clean, navigable layout.

The portfolio highlights my background in customer service, my transition into software engineering, and the projects I’m building with Python, APIs, and data processing tools.

## Features

- **Professional Introduction** — Background and career experience
- **Project Showcase** — Descriptions of software and data projects
- **Technical Skills** — Technologies and tools used across projects
- **Section Navigation** — Internal links for quick access to page content
- **Contact Information** — Email and GitHub profile links
- **Semantic HTML** — Structured content using modern HTML5 elements

## Technologies

- HTML5
- Semantic HTML
- Git
- GitHub


## HTML Concepts Demonstrated

- Document structure and metadata
- Semantic elements: `header`, `main`, `section`, `article`, and `footer`
- Heading hierarchy and content organization
- Navigation using anchor links and element IDs
- Hyperlinks and email links using `mailto:`
- Lists for presenting technical skills
- HTML attributes, including `href`, `id`, `lang`, and `target`
- Viewport configuration for mobile-friendly browser rendering

## Featured Projects

### Student Grade Tracker
A Python command-line application that processes student data from CSV files, calculates averages, and generates summary reports with error handling.

### Data Processing Pipeline
A data processing project using pandas to clean datasets, perform grouping and aggregation, and create visualizations with matplotlib.

### AI-Ready Task Manager API
A FastAPI backend featuring CRUD operations, SQLAlchemy database integration, JWT authentication, and automated testing with pytest.

## Getting Started

This project requires no additional dependencies.

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory.

3. Open `index.html` in your browser.
